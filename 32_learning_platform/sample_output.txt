    The ids were not passed in. _new_id() is a class method:
      cls._sequence += 1
      return f'{cls.ID_PREFIX}{cls._sequence:03d}'

    cls is Student for a student and Mentor for a mentor, so one
    method produces S001..S005 and M001..M002 from two counters:
      Student.ID_PREFIX / _sequence  -> S / 5
      Mentor.ID_PREFIX  / _sequence  -> M / 2
      User.ID_PREFIX    / _sequence  -> U / 0   <- never used, never moved

==============================================================
  6. What the platform refuses
==============================================================
      a duplicate email                   DuplicateUserError
                                            aarav@example.com is already registered as S001
      a malformed email                   ValidationError
                                            email 'nope' is not usable: must look like name@example.com
      a blank name                        ValidationError
                                            name '   ' is not usable: must be a non-empty string
      an unknown id                       UnknownUserError
                                            no user with id 'S999'
      a course for a mentor               ValidationError
                                            user 'M001' is not usable: is not a student
      an assignment before a course       ValidationError
                                            assignment 'Anything' is not usable: the student is not on a course yet
      the same assignment twice           ValidationError
                                            assignment 'Functions' is not usable: has already been submitted
      a fourth student for a full mentor  MentorFullError
                                            V. Krishnan already has 3 students, which is the maximum

    Eight different failures, one except clause. Every class above
    inherits from PlatformError:

        PlatformError
         |-- ValidationError
         |-- DuplicateUserError
         |-- UnknownUserError
         +-- MentorFullError

    MentorFullError carries the mentor and the limit, not just a
    sentence, so a caller can act on it:
      error.mentor.name -> V. Krishnan
      error.limit       -> 3

  7. The class variable and the class method, once more
==============================================================
    User.platform_name    -> Nova Learn
    Student.platform_name -> Nova Learn   <- inherited, not copied
    Mentor.platform_name  -> Nova Learn

    User.set_platform_name('Nova Learn Academy')
      S001  Aarav Sharma    Nova Learn Academy
      S002  Diya Menon      Nova Learn Academy
      M001  V. Krishnan     Nova Learn Academy

    User.total_users            -> 9
    Student.total_users         -> 9
    User.get_total_users()      -> 9
    site.total_users()          -> 8

    The two numbers differ on purpose, and the gap is exact:
      7 registered in section 1
      +1 'No Course', registered in section 6 and never given a course
      +1 'Someone Else', built and then refused for a duplicate email
    User.total_users counts every User object __init__ ever finished.
    site.total_users() counts the ones the platform actually kept.
    A class variable and a dictionary answer two different questions.
