==============================================================
  6. Validation - what the class refuses
==============================================================
    mark above 100     ValueError: score for 'Python' must be between 0 and 100, got 120
    negative mark      ValueError: score for 'Python' must be between 0 and 100, got -5
    mark is a string   ValueError: score for 'Python' must be a number, got 'eighty'
    mark is True       ValueError: score for 'Python' must be a number, got True
    empty subject      ValueError: subject must be a non-empty string

    True is rejected on purpose. bool subclasses int in Python, so
    isinstance(True, int) is True and a score of True would become
    1 - a silently wrong mark instead of a loud error.

    is_valid_email() is a static method: it needs no student.
      Student.is_valid_email('aarav@example.com'   ) -> True
      Student.is_valid_email('no-at-sign'          ) -> False
      Student.is_valid_email('two@@example.com'    ) -> False
      Student.is_valid_email('nodot@example'       ) -> False
      Student.is_valid_email('@example.com'        ) -> False
