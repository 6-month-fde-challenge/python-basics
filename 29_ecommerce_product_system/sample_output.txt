==============================================================
  1. A static method needs no object
==============================================================
    Product.get_total_products()  -> 0
    There is not a single product yet - and this still works:

      Product.is_valid_price(1299      ) -> True
      Product.is_valid_price(58990.5   ) -> True
      Product.is_valid_price(0         ) -> False
      Product.is_valid_price(-250      ) -> False
      Product.is_valid_price('999'     ) -> False
      Product.is_valid_price(True      ) -> False
      Product.is_valid_price(None      ) -> False

    is_valid_price() reads no attribute of any product. It takes a
    number and answers a question about that number, so it takes
    neither self nor cls:

        @staticmethod
        def is_valid_price(price):
            return price > 0

    True is rejected first. bool subclasses int, so True > 0 is
    True and a price of True would be stored as 1.00.

==============================================================
  5. What the shop refuses
==============================================================
    Notebook: 2 in stock
      more than the shelf holds    ValueError: cannot remove 5 of Notebook: only 2 in stock
      a negative quantity          ValueError: quantity must be a whole number above zero, got -2
      half a notebook              ValueError: quantity must be a whole number above zero, got 1.5
      a stock change of zero       ValueError: stock change of 0 does nothing
      removing more than exists    ValueError: cannot remove 99 of Notebook: only 2 in stock
      a 100% discount              ValueError: discount must be between 0 and 100, got 100
      a price of zero at build time ValueError: price must be greater than zero, got 0
      an unknown category          ValueError: unknown category 'Hardware' (known: Electronics, Home, Grocery, Fashion, Stationery)

    Notebook is still at 2 - a refused sale
    changes nothing, because sell() prices the order and checks the
    stock before it touches either number.

    And the boundary that is allowed:
      notebook.sell(2) -> 284.38   stock now 0
      notebook.in_stock()  -> False
